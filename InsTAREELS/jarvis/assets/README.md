# Jarvis HUD artwork

`jarvis-reference.gif` is the animation linked at the top of the README of
https://github.com/kishanrajput23/jarvis-desktop-voice-assistant
(reviewed at commit `1162b3ff99b251ccacdd1d1c76594c29ad4cfa57`).

Original asset URL: https://giffiles.alphacoders.com/212/212508.gif
Retrieved 2026-09-26. The bundled file is unchanged. The renderer selects the
J.A.R.V.I.S. circular logo from coordinates `(165, 520, 390, 745)` of the
1440 x 900 image and scales it for our controls. No network requests occur at
runtime. The repository's MIT license is retained at
`integrations/JARVIS-UI-LICENSE`; the external animation has separate provenance
and is not claimed to have been created by this project or covered by that
repository license. Iron Man/Stark/J.A.R.V.I.S. branding remains third-party
artwork, copied here for the user's requested personal interface.
