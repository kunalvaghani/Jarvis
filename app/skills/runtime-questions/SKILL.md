# Workflow

Use quick_answers for supported everyday questions. Read current local time/date and runtime weather/location providers; personalize from the Obsidian profile. Never use yesterday's weather or a cached answer as today's fact. The local profile location is a fallback, not proof of current physical location. Historical procedures identify providers and routing, not hardcoded answers. Report unavailable live data accurately.
