Natural-language F1 requests naming exactly one supported season route through
the existing neural compiler and dispatcher. The deterministic stages resolve
the target, acquire edition-specific official regulations, make one bounded
catalog search, record provenance and rejected/unacquired asset states, build
an explicitly authorized surrogate, check actual mesh/native physics, execute
the installed qualified CPU backend and independently verify recorded results.

Surrogate fallback must be explicit in the original request. Never reinterpret
an exact-team-only goal as permission for a class surrogate. Public catalog
metadata and CC license declarations do not establish acquired geometry or
exact proprietary engineering identity. Authenticated downloads remain separate.

Unknown inputs are labelled assumptions and intervals; the educational recipe
is neither a fitted team car nor full FIA regulatory compliance. Keep the
fixed road/controller scenario and the explicit wing parameter change. Report
observed speed and mechanical engine energy with their limits. No fuel/hybrid
or physical-validation claim follows from this workflow.

Use verified Journal stages on restart. Recheck their file hashes. A claimed or
uncertain side effect cannot run again automatically. Failed reads have at most
two admissions; no recursion-limit increase or arbitrary generated host code.
The final project verifier must inspect every stage and the actual solver
admission/completion receipts before completion.
