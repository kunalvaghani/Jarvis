description: Inspect the existing Discovery neuron contracts, routing eligibility, typed scientific references and retained learning proof without running solvers or models.

Requires lab.enabled in an authorized scope; shipped flags remain off.

Use `lab audit integration` for a fresh inventory and comparison with the preceding audit in the same brain Journal. Use `lab memory wire` to reconcile resolvable forward references into the existing typed edge index. Neither command installs tools, invokes a model/solver, changes permissions, promotes a capability, or writes to an external application.

Distinguish a verified inspection from an inspection whose result says passed=false. Report missing descriptors, handlers, source/test/skill paths, dangling dependencies, incompatible ports, corrupted artifacts, unresolved typed references and unsupported VERIFIED states. Test paths identify checks; they are not proof those checks ran. Eligibility comes from the existing hard policy, and needs_approval remains separate.

Typed source and artifact fields become requires edges; tool fields become uses_tool edges. Preserve authored supports/contradicts/derived_from evidence links and captured revisions. A target is never invented for a missing reference. Retained failed-tool gap episodes can legitimately identify a tool not registered yet; display that gap as a notice. More than the declared scan bounds fails inspection rather than hiding records.

All scientific bodies remain in the existing Journal/LabMemory. The name resolver reuses jarvis.names.rank, returns typed records, and keeps ambiguous candidates; it invents no aliases. Cross-project use retains the record's evidence status and source context.
