# Voice verification fixture provenance — 2026-10-23 IST

No file in this packet is a private microphone recording. No speaker playback or physical capture was performed. Raw model files are intentionally outside Git.

- `fleurs-{en,hi,gu,fr}-{0,1,2}.wav`: public Google FLEURS test recordings, retrieved from the [MTEB repackaging](https://huggingface.co/datasets/mteb/fleurs) of [Google FLEURS](https://huggingface.co/datasets/google/fleurs). Credit: Google FLEURS dataset contributors and the MTEB dataset maintainers. Distributed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), as declared by the dataset card. Exact config, split, offset, row ID, source, reference text and SHA-256 are in `multilingual-fixtures.json`. The downloaded audio bytes were retained unchanged; temporary CDN URLs were discarded. `public-gujarati-fixture.wav` is the separately retrieved first Gujarati test clip, with its receipt in `gu-fixture-row-metadata.json`.
- `public-fixture.wav`: generated public English text, “Jarvis open calculator.”, using the existing Kokoro model and English voice. `public-french-fixture.wav`: generated public French text, “Bonjour, comment allez-vous ?”, using the already-installed Kokoro `ff_siwis` style and French phonemizer. See [Kokoro voice information](https://huggingface.co/hexgrad/Kokoro-82M/blob/main/VOICES.md). These generated examples are not human-acoustic accuracy tests.
- `public-hindi-fixture.wav`: generated public text, “नमस्ते, आप कैसे हैं?”, using the installed Piper Hindi Rohan model. Existing asset/source attributions in the application continue to apply.
- `mixed-en-hi.wav` and `mixed-en-fr.wav`: generated public mixed-language texts, with exact references in `mixed-fixtures.json`. `mixed-en-gu-spliced.wav` concatenates generated English, 100 ms silence and the first public Gujarati clip. This is an edited two-speaker fixture, not a natural code-switching recording; the Gujarati portion retains the FLEURS CC BY 4.0 attribution above.
- `voice-states-rendered.png`: actual Jarvis header-renderer output with synthetic captions, authored for this report. It is not a desktop screenshot, physical audio test or a depiction of accepted Gujarati recognition.

The ASR test results intentionally retain failures. Word error rates use the script's documented normalization; they are diagnostic measurements, not broad performance guarantees. The English medium.en configuration remains selected. Medium and turbo multilingual weights were separately approved, pinned and verified; download receipts and model-source links are recorded alongside the reports. No dependency or driver installation occurred.
