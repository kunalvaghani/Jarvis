`browser_extension/jarvis/background.js` + `browser_extension/host/jarvis_browser_host.py` + `control/web/extension_runner.py` already provide authenticated localhost/native messaging, session-owned tabs, snapshots and reads. The extension intentionally has **no downloads permission or command**. `webmcp.py` is optional/page-bound and disabled unless host policies authorize it. `control/routes/browser.py` has a separate existing Playwright download callback. `control/web/agent_browser_backend.py` puts download commands behind confirmation.

`discovery/adapters/asset_catalog.py` searches bounded public Sketchfab metadata only. `adapters/assets.py` validates supplied local-file provenance/license claims and caches inert files, with a 500 KB Journal-cache limit; it is not a downloader or geometry parser. `model/component_graph.py` provides typed component/parameter dependencies. `mechanical_flow.py` requires a prepared primitive mechanics JSON. `scenario_project.py` builds an educational class surrogate from a fixed recipe; it does not ingest acquired vehicle geometry. `chrono_vehicle_worker.py` instantiates real native multibody dynamics from BSD Sedan topology with labelled educational assumptions. No interactive asset decomposition/playback workbench is wired to that path.
