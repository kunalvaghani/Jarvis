## 2A. Brain on, with neurons that grow and retire (done 2026-11-04)

| Lifecycle step | How it works now | What the Lab does with it |
|---|---|---|
| Activate | `neural.mode = act`: known workflows run through the brain, everything else through the legacy planner unchanged | Every Lab capability is a neuron the brain fires; no Lab code is called outside the brain |
| Grow (make) | `neural/lifecycle.tick`, every 10 finished brain goals: `learning.consolidate` turns a tool chain verified at least 3 times into a proposed composite neuron. Read-only composites activate; anything that writes waits for the user's approval (`python -m jarvis.neural approve <id>`) | Lab neurons learned through the golden gate (B5) enter as proposed, become `LEARNED_UNVERIFIED`, then active after 3 independent code-checked uses |
| Retire (delete) | The same tick disables a *learned* neuron with at least 5 judged runs under 40 % verified success, journalled with the reason. Built-in, tool and MCP neurons are only retired by the user (`retire`, `restore`); a retirement survives restarts | A Lab neuron whose golden test or verified uses regress is retired, not silently kept; `invalidates` edges mark dependants for re-check |
| Evidence | Only verified outcomes count (independent verifiers, not self-reports); eligibility (permissions, privacy, approvals) is never learned | Lab results enter the journal with their evidence status; "no number from an LLM" is a verifier rule |
| Rollback | `JARVIS_BRAIN_MODE=off` (one step, no config edit); `neural.learning off` returns routing to priors | Flags-off Lab = Jarvis as before |
